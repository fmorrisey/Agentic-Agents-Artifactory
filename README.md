# Agentic-Agents-Artifactory
A collection of AI Agents used in coding tasks, planning, and maybe even baking sourdough 🍞 ???

## Agents

### Coding

| Agent | Model | Description |
|-------|-------|-------------|
| **Code Reviewer** | Opus | An elite code reviewer focused on security, performance, and architecture. Conducts thorough, actionable reviews covering OWASP Top 10 vulnerabilities, algorithmic efficiency, maintainability, and testing coverage. |
| **Software Architect** | Opus | A Staff+ level software architect that provides pragmatic architecture support including system design tradeoffs, risk analysis, security posture review, and operational readiness. Turns ideas into clear, implementable plans while highlighting hidden pitfalls early. |

### Culinary

| Agent | Model | Description |
|-------|-------|-------------|
| **Baker** | Sonnet | An expert artisan baking assistant specializing in sourdough, naturally leavened breads, and historical recipes. Helps bakers troubleshoot dough, manage starters, and adapt techniques — thinking like a baker rather than a recipe app. |
